Session Documentation Packet

Combine the attendance log, SOAP note, child goal data and parent fidelity for one session into a single family-facing PDF.
🔒 Confidential — nothing leaves this browser. Client information you paste here stays in this page's memory only: it is not sent anywhere and is not saved to disk. Closing or refreshing the tab erases it. Use Print / Save as PDF to create the document for the family, then save the PDF where client files belong.

Attendance Tracker

▾
📋 Paste from ShareVision

Open the attendance log entry in ShareVision, select the record (labels and values), copy, and paste below. The tool looks for labels such as Session Number, Date of Session, Status, Chapter/Topic, Location, Attendance Notes. Anything it can't match is left for you to place by hand.

2

SOAP Note

▾
📋 Paste from ShareVision

Paste the whole SOAP note. The tool splits it at the Subjective, Objective, Assessment and Plan headings (or S:, O:, A:, P:). If it can't find headings, everything goes into Subjective for you to move.

⚠ Review before printing: the Plan section often holds notes-to-self (reminders, referrals to submit). Reword or remove anything not written for the family.

3

Child Goal Data

▾
📋 Paste from the child data sheet

In the child's data workbook, select this session's three columns for all goals (from the first goal's date cell down to the last goal's summary rows), copy, and paste here. Each goal block is read as: date, baseline step, teaching steps 1–5, then the three summary rows.

Other format? Paste any Excel range as a plain table instead
4

Parent Coaching Fidelity

▾
📋 Paste from the parent fidelity sheet

Select this session's column in the fidelity sheet (date, the 13 category scores, actual score, possible score, percentage), copy, and paste here. Pasting the category labels alongside is fine too.

Other format? Paste any Excel range as a plain table instead
