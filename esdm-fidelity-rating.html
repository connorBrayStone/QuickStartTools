Feedback

Where is this saved?
  • Only in this browser on this computer. Nothing is sent anywhere, backed up or synced. It won't appear in another browser, on another computer or in a private window, and it's lost if browser data is cleared.
  • This tool is not a record. Print the sheet or export the file and keep it wherever your supervision records go.
  • Use the child's initials only.
  • To pass an observation between people (for example, a self-rating then the supervisor's rating), use Export .json and Import .json. Importing an observation that is already here replaces the copy here.
  • The item descriptions, if you load them, are kept in this browser too. Remove in the panel at the top clears them.
Items, scale and fidelity criteria: Early Start Denver Model Fidelity Rating System, in Early Start Denver Model for Young Autistic Children, 2nd edition, by Sally J.
